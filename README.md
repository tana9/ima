# ima

今していることを Google カレンダーの専用カレンダーに記録する、Google Apps Script の Web アプリです。

## 構成

ビルドやフロントエンドの依存パッケージは不要です。Apps Script の HTML テンプレートで各ファイルを読み込みます。

| ファイル | 役割 |
| --- | --- |
| `src/Index.html` | 画面のHTMLと各ファイルの読み込み |
| `src/Styles.html` | CSS |
| `src/DateTime.html` | ブラウザのローカル日時の変換・計算・検証。DOMと通信に依存しない |
| `src/Api.html` | `google.script.run` のPromise化と共通のエラー表示 |
| `src/State.html` | 画面状態、編集下書き、読み込み、操作ロックの管理 |
| `src/App.html` | 状態を表示する処理とユーザー操作 |
| `src/Code.gs` | カレンダー・Drive操作、画面全体のデータ取得、テンプレート配信 |
| `src/DateValidation.gs` | サーバーで必ず実施する日時・期間の検証 |
| `src/appsscript.json` | Apps Scriptの設定と必要な権限 |

状態・今日の記録・候補一覧は `getDashboard()` でまとめて取得します。古いリクエストの結果は破棄します。
画面に影響する非同期操作は `runAction()` を通し、確認中・処理中の二重操作を防ぎます。
開始・保存に失敗した場合は入力を残し、再読み込みしても編集中の下書きを保持します。

終了欄の日時は端末のローカル時刻です。サーバーにはミリ秒のタイムスタンプを送ります。
明示的に指定した終了日時が開始日時以前の場合は、記録を変更せずエラーを表示します。
記録の編集で時刻を変更していない場合は、表示されない秒・ミリ秒も保持します。
「今日」の一覧は Apps Script プロジェクトのタイムゾーン（Asia/Tokyo）を基準にします。

## テスト

Node.js で実行します。外部パッケージのインストールは不要です。

```sh
node --test tests/regression.test.cjs tests/app.test.cjs
```

日時の境界条件、入力検証、通信失敗、二重操作、応答順の逆転、編集下書きの保持を確認します。
GoogleサービスとDOMはモックを使うため、Googleの権限や実ブラウザでの表示は別途確認が必要です。

## Apps Scriptへの反映

既存の `.clasp.json` の `rootDir` は `src` です。追加したHTML・GSファイルも含めて反映してください。
Webアプリをバージョン指定で公開している場合は、デプロイ先のバージョンも更新します。

画像添付には `DriveApp` が必要とする `drive` スコープを使用しています。以前の `drive.file` から切り替えた後は、利用時に権限の再承認が必要です。
添付画像はリンクを知っている人が閲覧できる設定で保存します。
